# Contributing to ISC Labs

Thanks for helping. This project exists so any Class 12 student can do the practicals, even without a lab, so every fix helps real students.

## Ways to help

- **Report a mistake.** A wrong observation, formula, reading or colour change in an experiment? Open an issue and name the experiment and the step.
- **Suggest an experiment.** Open an issue with the board (ISC or CBSE), the experiment name, and the syllabus reference if you have it.
- **Improve a lab.** Fork the repo, change the lab file, and send a pull request.
- **Translate or simplify.** Hindi, Gujarati and Urdu versions of the instructions would help many students.

## Pull request basics

- One experiment or one fix per pull request.
- Say which experiment you changed and how you tested it, for example "ran the full procedure on Chrome and on a phone".
- Each lab is a single HTML file with the app source inside it, so keep your change small and easy to review.

## Teachers

If you teach these practicals and something doesn't match your board's procedure, please tell us. Your correction is more useful than a new feature.
